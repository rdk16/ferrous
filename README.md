# Linguagem de Programação **Ferrous**

### Segura, Poderosa e Simples (ou Não).

---

#### Caracteristicas

- **Simplicidade**: Ferrous traz uma sintaxe completamente simplificada e com
  design moderno.
- **Poderosa**: Ferrous traz uma poderosa engine para o seu ambiente de
  desenvolvimento.
- **Segurança**: Ferrous traz um tratamento de tipos e erros muito poderoso e
  amigável, evitando erros.

> [!IMPORTANT]
> Esta linguagem está em desenvolvimento.
